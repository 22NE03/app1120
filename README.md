# 🎓 출튀를 잡아라 (YOLOv8 강의실 인원 변화 확인)

> 배포 링크 : https://app1120.streamlit.app/

강의실 사진을 시간 순서대로(예: 10분마다 1장) 올리거나 휴대폰 카메라로 찍으면, AI가 사진마다 사람 머리를 찾아 인원 수를 세고, 회차별 인원 변화를 표와 그래프로 보여 주는 웹 앱입니다. 
1회차(출석 때)보다 인원이 줄면 "출튀 의심" 경고를 띄우고, 교수님이 출석을 다시 불러 확인할 수 있게 합니다. AI가 틀린 부분은 사용자가 직접 고칠 수 있습니다.

## 1. 주제 및 만든 이유
- **주제:** 수업 중 강의실 인원 변화를 자동으로 확인하는 "출튀 감지기"
- **만든 이유:** 출석을 부른 뒤 수업 중간에 몰래 나가는 "출튀"는 눈으로 일일이 세기 어렵습니다. 사진으로 인원을 자동으로 세고 출석 때와 비교하면 몇 명이 나갔는지 바로 알 수 있다고 생각했습니다.
- **결과 활용:** 10분마다 찍은 사진을 차례로 올리면 회차별 인원 그래프가 그려지고, 1회차보다 줄어든 인원을 알려 줍니다.
- **사용자 정정 기능:**
  - "머리 아님": 가방처럼 잘못 잡힌 박스를 사진에서 누르면 그 자리를 모든 회차에서 빼고 셉니다. (CCTV는 고정이라 가방도 매번 같은 자리에 잡히기 때문)
  - 제외한 자리에 나중에 학생이 앉으면 그 자리만 해제해서 다시 셀 수 있습니다.
  - "이건 머리야": AI가 놓친 머리를 사진에서 눌러 추가합니다. (그 회차 사진에만 적용, 취소 가능)
  - 수정은 모드(놓친 머리 추가 / 머리 아님 제외 / 제외 취소)를 하나 골라 고치고 "완료"를 누르는 방식이라 실수로 다른 것을 바꾸지 않습니다.
  - 다 고친 회차는 "확정"을 누르면 인원이 고정됩니다. 다시 고쳐야 하면 "다시 수정하기"로 풀 수 있습니다.
- **개인정보:** 얼굴을 인식하거나 저장하지 않고 "머리 위치와 수"만 사용합니다. 사진은 브라우저 세션에만 잠깐 보관되고 서버에 저장되지 않으며, "사진 모두 삭제" 버튼으로 바로 지울 수 있습니다.

## 2. 사용 모델 / 라이브러리

| 구분 | 이름 | 용도 |

## 4. 어려웠던 점과 해결 방법

- **배포 서버에는 웹캠이 없다:** OpenCV로 웹캠을 여는 방식은 내 노트북에서만 되고 배포 서버에서는 동작하지 않았습니다. 
→ Streamlit의 `st.camera_input`을 사용해, 접속한 사람의 브라우저(휴대폰 카메라)로 직접 찍도록 바꿨습니다. 
  기존 목표 : 추후 10분마다 자동 촬영 방식 / 한계 : 지금은 회차마다 사진을 추가하는 방식으로 만들었습니다.
- **GPU가 없는 환경:** 배포 서버와 노트북 모두 GPU가 없습니다. → 가장 가벼운 `yolov8n` 크기 모델을 쓰고, requirements.txt에서 CPU 전용 PyTorch를 받도록 설정했습니다.
- **버튼을 누를 때마다 처음부터 다시 실행되는 문제:** Streamlit은 버튼을 누를 때마다 코드 전체가 다시 실행됩니다. → 모델은 `@st.cache_resource`로 한 번만 불러오고, 처리한 사진 결과는 `st.session_state`에 누적해서 다시 계산하지 않게 했습니다.
- **강의실 CCTV에서 사람을 대부분 못 잡는 문제:** 기본 YOLOv8n(사람 전체 탐지)은 50명 정도 있는 강의실에서 3~6명밖에 못 잡았고, 민감도를 낮추면 책상에 가려진 한 사람이 다리·몸으로 나뉘어 2~3명으로 세어졌습니다. 엎드린 학생은 민감도를 최저로 내려도 잡히지 않았습니다. 정답 인원이 있는 CCTV 사진 40장(카메라 4대)으로 방법을 비교했습니다.

  | 방법 | 사진 1장당 평균 오차 |
  |---|---|
  | 기본 사람 탐지 (해상도 640, 민감도 0.35) | 약 37명 |
  | 사람 탐지 + 해상도 1280 + 사진 조각 탐지 + 중복 박스 정리 | 약 4.5명 |
  | **머리 탐지 모델 + 사진 조각 탐지 (최종)** | **약 2.6명** |

  → 위에서 찍은 CCTV에서는 몸은 가려도 머리는 거의 항상 보이고, 한 사람당 머리는 하나라서 중복도 줄어 머리 탐지 모델을 최종으로 골랐습니다. 객체 탐지 YOLO -> 머리 탐지 YOLO 
  
- **얼굴 기준 탐지를 쓰지 않은 이유:** 학생들이 고개를 숙이고 있으면 얼굴이 보이지 않고, 개인정보 측면에서도 얼굴을 쓰지 않는 편이 낫다고 판단했습니다. 머리 탐지는 정수리만 보여도 됩니다.
- **AI가 틀린 결과를 바로잡는 방법:** 가방을 머리로 잡거나 머리를 놓치는 경우가 있었습니다. 모델을 다시 학습시키는 건 앱 안에서 할 수 없어서, 고정 CCTV라는 점을 이용해 "그 자리 제외"와 "직접 추가" 방식으로 해결했습니다. Streamlit 기본 기능으로는 사진 속 박스를 누를 수 없어서, 사진 터치 좌표를 받는 부품(streamlit-image-coordinates)을 써서, 누른 위치에서 가장 가까운 박스를 고르거나 새 박스를 추가하도록 만들었습니다.
- **남은 한계:** 검은 가방이 머리로 잘못 잡히는 경우가 가끔 있고, 사진마다 2~3명 정도 오차가 있습니다. 그래서 같은 카메라로 찍은 사진끼리 인원 변화를 비교하는 용도로 사용합니다.
= 직접 수정이 가능하게 수정 기능을 추가 / 설명을 통해 사람 이동이 없는 경우에 사용을 권유하며, 이동이 많은 경우에는 탐지가 어렵다고 설명. 

## 실행 방법 (로컬)

```bash
pip install -r requirements.txt
streamlit run app.py
```

`models/head_yolov8n_scut.onnx` 파일이 `app.py`와 같은 위치의 `models` 폴더 안에 있어야 합니다.
